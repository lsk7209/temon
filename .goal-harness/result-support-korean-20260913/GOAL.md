# Goal

## Final Deliverable
Remove English topic labels from FAQ, use-case, JSON-LD, and visible support copy on eight static result pages without changing topic-specific helper behavior.

## User Value
Korean result pages no longer mix English test names into otherwise Korean guidance and structured FAQ content.

## Required Features
- Korean support-copy titles in all eight scoped result pages.
- Korean topic aliases select the same FAQ/use-case branches as the existing English titles.
- Translate the two visible `Interpretation Notes` headings.

## Non-Goals
- No scoring, result lookup, data-key, metadata, canonical, index-policy, participant/rating, push, or deployment changes.

## Done Conditions
- Failing-first focused regression, typecheck, lint, production build, and local HTTP content smoke pass.
