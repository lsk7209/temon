확인일: **2026-09-13**. 정책은 실행 시 다시 확인한다. 문서의 [Sxx]는 공식 지침/웹 API 명세, [Wxx]는 temon 공개 페이지 관찰이다. 정책의 모든 세부 조건을 이 파일이 대체하지 않는다.
